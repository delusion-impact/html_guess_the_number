# Угадай число

Небольшая браузерная игра: нужно угадать загаданное число от **1 до 20**.

Чтобы начать играть, откройте `index.html` в браузере.

## Правила

- В каждом раунде загадывается случайное число от 1 до 20.
- В начале раунда у вас **20** очков.
- Введите число и нажмите **Проверка** (или Enter).
- После неверной попытки игра подскажет «больше» или «меньше», а счёт уменьшится на 1.
- Если угадали — победа. Если счёт стал **0** — проигрыш.
- Кнопка **Снова** начинает новый раунд. Рекорд сохраняется, пока не перезагрузить страницу.

## Код

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка: шапка, поле ввода, счёт и рекорд |
| `css/styles.css` | Вёрстка и цвета фона при победе и проигрыше |
| `js/game.js` | Состояние игры, случайное число, обработка проверки и сброса |
